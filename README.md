Insights into the American Parliamentary Debate Association (APDA)

## Dependencies

### Built-in Libraries
* `pathlib` (Path) – For handling file system paths.
* `re` – For regular expression matching and text manipulation.
* `logging` – For tracking events and debugging.
* `io` (StringIO) – For handling text data as in-memory file streams.

### Third-Party Packages
* `beautifulsoup4` (BeautifulSoup) – For parsing HTML and XML documents.
* `duckdb` – For fast, in-process analytical SQL queries.
* `pandas` – For data manipulation and analysis.
* `numpy` – For numerical operations and array handling.
* `scipy` (stats) – For statistical functions and distributions.
* `matplotlib` (pyplot) – For creating static, animated, and interactive visualizations.
* `seaborn` – For statistical data visualization based on matplotlib.
* `pdfplumber` – For extracting text and data from PDF files.
* `Levenshtein` – For computing name similarities and edit distances.
